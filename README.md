# Бозшаколь: цифровой двойник медного рудника на OpenEgiz

Модель реального медного рудника Бозшаколь (KAZ Minerals, Павлодарская область, Казахстан): карьер, сульфидная фабрика ОФ-1 и глинистая фабрика ОФ-2 (упрощённо). В модели карьер 4 070 × 880 м глубиной 225 м, 31 самосвал, 6 экскаваторов, 4 буровых станка, дробилка, конвейер, склад дроблёной руды, мельницы и флотация ОФ-1, фабрика глинистых руд ОФ-2 со складом глинистой руды, общий склад концентрата и хвостохранилище. Двойником пользуется начальник смены. Он видит рудник в 3D и на плане, проигрывает последствия сбоев на 12 часов вперёд и получает от советника варианты действий с оценкой в тоннах меди и тенге: куда везти руду забоя, который оказался глинистым, и стоит ли платить второй бригаде за ускоренный ремонт. Цифры откалиброваны по открытым отчётам KAZ Minerals; модель построена по публичным данным и не связана с оператором рудника.

Все объекты рудника — двойники в Eclipse Ditto: 194 двойника, из них 171 объект рудника и 23 служебных (модули, сценарии, прогнозы, журнал). Данные идут через платформу OpenEgiz (MQTT → Ditto → Telegraf → InfluxDB), страница рудника получает их из платформы.

Описание решения, модулей, сценариев и допущений — в [SUBMISSION.md](SUBMISSION.md). Документация платформы — в [OPENEGIZ.md](OPENEGIZ.md).

## Запуск с нуля

Нужны Ubuntu 24.04 (amd64) с Docker Engine и Docker Compose v2, 8 ядер, 16 ГБ памяти, доступ в интернет. Команды выполняются из корня репозитория:

```bash
sudo apt-get update && sudo apt-get install -y make curl
make mine
```

`make mine` поднимает платформу OpenEgiz и сервисы рудника, ждёт готовности (двойники, телеметрия, история, страница) и в конце печатает:

```
Bozshakol mine model is running: http://localhost:8088
```

Первый запуск скачивает около 6 ГБ образов и занимает 7–15 минут, в зависимости от сети. Повторный запуск при скачанных образах — около полутора минут (после `make clean` — 79 с). Если платформа не стартовала с первого раза (например, из-за таймаута Docker Hub), `make mine` сам повторяет попытку.

## Что открыть

| Адрес | Что там |
|---|---|
| http://localhost:8088 | Страница рудника: 3D-вид карьера и обеих фабрик в двух стилях («Голограмма» и «Реалистичный»), план, объекты, сценарии «что если», модули, прогноз на 12 ч, советник, журнал событий, панель «О модели» |
| http://localhost:3000/d/bozshakol-history | История в Grafana («Бозшаколь — история»), открывается без входа, только просмотр. Приложение OpenEgiz (двойники, иерархия) — после входа: логин `admin`, пароль: `grep GRAFANA_ADMIN_PASSWORD deploy/compose/.env` |
| http://localhost:8080/api/2/things | REST API Eclipse Ditto. Логин `ditto`, пароль: `grep '^DITTO_PASSWORD' deploy/compose/.env` |

Как пользоваться страницей, объясняют кнопки «Справка» и «О модели» в правом верхнем углу.

## Проверка и остановка

| Команда | Что делает |
|---|---|
| `make mine-check` | Полная проверка стенда: двойники, телеметрия, история, шлюз страницы, все семь сценариев, модули, ресурсы смены, прогноз и советник (около 2,5 минуты) |
| `make mine-test` | 208 тестов симулятора и модулей (балансы массы и меди, детерминизм, сценарии, глинистая руда, ресурсы смены, эффект модулей, советник), около 11 минут |
| `make mine-logs` | Журналы сервисов рудника |
| `make mine-down` | Останавливает рудник и платформу, данные сохраняются |
| `make clean` | Удаляет всё, включая данные и сгенерированные пароли |
